
Student Grading System

This project is a Student Grading System written in Python. It allows to manage student info including:
-Student ID
-Name
-Grades for subjects (Math or English)

What It Does:
-Add new student records
-Update existing student grades
-Delete student records
-Search for students by name or ID
-Display Pass/Fail per subject

How to Run:
Open main.py and run it. When picking option 1, you will be asked to enter:

-Student ID
-Name
-Grades for Math and English

Then use the menu to update, delete, or search records.

How to Test:
Run the test file and you’ll see printed results confirming whether each test passed.

Requirements:
-No external libraries required
